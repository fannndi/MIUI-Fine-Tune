#   lib:perfd                   = strings vendor/lib64/libqti-perfd.so (OptsHandler implementations)
#   netd                        = /system/bin/netd (only literal tcp_rmem in the ROM) called by
#                                 ConnectivityService with LinkProperties.TcpBufferSizes

#                                 across display-off cycles — tools/display-off-diff.sh)
